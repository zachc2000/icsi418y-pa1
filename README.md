## Description
TaskMaster is a simple client-side web application for managing tasks. Users can add a task, choose a Low, Medium, or High priority, mark tasks as completed, and delete tasks.

The application also includes import, export, and clear-all options. Tasks can be exported to a JSON file and imported again later.

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the form to enter a task name, choose a priority, and click **Add Task**.

No installation, server, or external libraries are required.

## Features
- Add new tasks
- Assign Low, Medium, or High priority
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks
- Import tasks from a JSON file
- Export tasks to a JSON file
